# ONDAS – IRONWAVE Technical Help: מדריך הקמה ועדכון

## הקמה (פעם אחת, כ־15 דקות)

1. **פתיחת חשבון:** היכנסו ל־github.com ופתחו חשבון חינמי.
2. **יצירת מאגר:** לחצו New repository. תנו שם (למשל `ondas-help`), בחרו **Public** ולחצו Create repository.
   באתר החינמי של GitHub (Pages) המאגר חייב להיות ציבורי. מי שיודע את הכתובת יכול להגיע לקבצים, גם בלי הסיסמה. לכן מכניסים רק תוכן שמותר שיהיה גלוי.
3. **העלאת הקבצים:** במאגר החדש לחצו uploading an existing file. גררו את **כל** מה שבתיקייה הזו: index.html, sw.js, manifest.webmanifest, content.json, הסמלים, ותיקיות lib ו־media. לחצו Commit changes.
4. **הפעלת האתר:** היכנסו ל־Settings ← Pages. תחת Branch בחרו `main` ואת התיקייה `/ (root)` ולחצו Save.
   אחרי 1–2 דקות תופיע הכתובת, למשל `https://YOUR-NAME.github.io/ondas-help/`.
5. **החלפת סיסמאות:** פתחו את הכתובת והיכנסו עם סיסמת הצוות `field123`.
   - לחצו ? ← כניסת מנהלים, עם הסיסמה `admin123`.
   - לחצו "סיסמאות" והגדירו סיסמאות חדשות.
   - לחצו "פרסום גרסה" והעלו את הקובץ שנוצר, כפי שמוסבר בהמשך.
6. **שליחה לצוות:** שלחו לטכנאים את הכתובת ואת סיסמת הצוות. ההוראות להתקנה בטלפון ובמחשב מופיעות בתוך האפליקציה, תחת ?.

## הוספה ועדכון של תוכן

1. **כניסה למצב עריכה:** באפליקציה לחצו ? ← כניסת מנהלים.
2. **עריכה:** הוסיפו וערכו נושאים ופריטים, בעברית ובאנגלית. הטיוטה נשמרת בדפדפן שלכם עד הפרסום.
3. **פרסום:** לחצו "פרסום גרסה". יירד הקובץ `ondas-update.zip`.
4. **חילוץ:** חלצו את הקובץ.
5. **העלאה:** ב־GitHub לחצו Add file ← Upload files, גררו את `content.json` ואת תיקיית `media`, ולחצו Commit changes.
6. **ניקוי הטיוטה:** באפליקציה לחצו "העליתי ל־GitHub".
7. **הודעה לצוות:** כתבו לטכנאים: "יצאה גרסה X, לחצו על שמירה במכשיר".

## מגבלות שכדאי לדעת

- **גודל קובץ:** קובץ בודד עד 25MB, כי זו המגבלה של העלאה דרך הדפדפן ב־GitHub. גודל כולל מומלץ: עד 1GB.
- **תמונות:** תמונות גדולות מוקטנות אוטומטית בזמן ההוספה.
- **קבצי התקנה:** הם לא נכנסים לאפליקציה. כל טכנאי מעתיק אותם מהשרת של החברה למחשב הנייד. באפליקציה יש לכל תוכנה כרטיס עם הגרסה העדכנית והמיקום שלה.
- **סיסמה:** הסיסמה מונעת כניסה מקרית בלבד. היא לא אבטחה חזקה.
- **עריכה במקביל:** כל מנהל עורך בדפדפן שלו. אם שני מנהלים מפרסמים במקביל, הפרסום האחרון דורס את הקודם. לכן כדאי לתאם, או שמנהל אחד יפרסם.

## בדיקות ATP Field

- **איפה הבדיקות נשמרות:** כל בדיקה שמורה בהיסטוריה של המכשיר שעליו היא בוצעה, ונוצר ממנה קובץ PDF להורדה או לשיתוף. האפליקציה לא מעלה את הבדיקות לשום מקום.
- **שמירת עותק:** שמרו או שלחו את קובץ ה־PDF מיד אחרי כל בדיקה. אם מנקים את הדפדפן או מחליפים מכשיר, ההיסטוריה נמחקת.
- **עדכון שורות הבדיקה:** במצב עריכה, בפריט ATP Field. שורה שמתחילה ב־# היא כותרת של פרק.
